# Pixel Editor

A Java Swing-based pixel art editor featuring layered drawing, multiple drawing tools, image filters, undo/redo, zoom controls, colour selection, and PNG import/export.

## Features

- Pencil and eraser tools
- Fill and eyedropper tools
- Shape and text tools
- Multiple image layers
- Layer reordering and merging
- Undo and redo
- Zoom and pan controls
- Colour picker
- Image filters
- PNG saving and loading
- Adjustable canvas dimensions

## Technologies

- Java
- Java Swing
- Java AWT
- BufferedImage

## Project Structure

```text
Source/
    Java source files for the editor

Icons/
    PNG assets used for toolbar and interface icons
```

## Running the Project

Compile the Java source files and run `Driver.java`, which serves as the application's entry point.

```bash
javac Source/*.java
java -cp Source Driver
```
